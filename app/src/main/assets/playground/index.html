पहली बार setup

  1. Main app खोलें और Enable Device Automation दबाएँ।
  2. Android Accessibility settings में Needle 2 Device Automation ON करें।
  3. Main app में वापस आएँ और Chrome playground खोलें।
  4. अब natural-language commands दे सकते हैं।

Important: Accessibility permission user द्वारा manually ON करनी होती है।

Automation capabilities

  • Visible screen text पढ़ना
  • Text/accessibility label से tap
  • Text typing
  • Coordinate tap और swipe
  • Back / Home
  • Installed app launch
  • Browser URL खोलना
  • Battery और local time

Android security limits के कारण हर privileged system setting या protected operation को बिना user permission control नहीं किया जा सकता।
